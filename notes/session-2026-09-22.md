## Letting a cloud session reach thecardhuddle.com

Two separate blocks stand in the way:

- **The Claude session's egress policy.** The default environment refuses the domain. Fix: **New** session → environment picker above the message box → gear on the environment (or **Add cloud environment**) → Network access **Custom**, allowed domains `thecardhuddle.com` and `*.thecardhuddle.com`, and tick "Also include default list of common package managers". A running session can't change environment.
- **Cloudflare Bot Fight Mode.** The domain is on the Free plan; Workers Paid is account-level and doesn't change bot protection. Free Bot Fight Mode can't be bypassed by a WAF skip rule. Switch it off while Claude pulls the data, then back on. (Super Bot Fight Mode on Pro+ does honor a skip rule on a secret header.)
